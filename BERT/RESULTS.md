## 실험 조건

- 모델: `textattack/bert-base-uncased-SST-2`, BF16, 길이 128, `cpu_fallback=False`, attention 구현 `sdpa`
- 마스크: `create_bidirectional_mask`를 passthrough로 패치하고 4D additive mask를 CPU에서 만들어 NPU로 넘김 (step4 방식)
- 입력: step4의 실제 문장을 128로 패딩함. batch B는 1~B번 문장 (batch [1, 2, 4, 8, 16]), id는 int32
- PE: 별도 설정 없이 SDK 기본값 사용, `furiosa:0`. 실제 적용값은 `(Fusion(num_fusion=1, num_pe_per_cluster=1, num_chips=1, num_clusters_per_chip=1))`라서 1 PE임
- 한 번 실행할 때마다 첫 호출 1회 + 워밍업 10회 + 반복 50회. 조건마다 새 프로세스로 3세트 실행함. 실행 순서는 회차마다 바꿈
- 대표값: 반복 150회(세트 3개 × 50회)를 모두 모은 평균 ± 표준편차. 중앙값과 세트별 평균도 같이 적음. 정상 종료한 세트만 포함함
- 첫 호출은 성능 비교에서 빼고 기록만 함. 첫 호출·워밍업 합·A는 세트 3개의 중앙값 (min~max)
- 캐시: 실행마다 `runs/<id>/caches/<stage>/<case>`를 새로 만들어 씀. 팀 공용 캐시는 사용하지 않음
- 타이머: `stream.synchronize()` → `perf_counter_ns` → `runner(**inputs)` → `stream.synchronize()`. 입력 전송과 출력 CPU 복사는 타이머 밖임
- A = runner 준비(S) + 첫 호출(F) + 워밍업 합(W). 모델 로드와 NPU 전송 시간은 제외함. T(N) = A + N × 반복 평균
- NPU 사용 시간 합계 5048초 (예산 14400초)
